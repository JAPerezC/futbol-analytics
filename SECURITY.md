# Política de Seguridad

## Versiones soportadas

Solo la rama `main` recibe parches de seguridad activamente.

## Reportar una vulnerabilidad

**No abras un issue público para reportar vulnerabilidades.**

1. Usa GitHub Security Advisories: pestaña **Security** del repo > **Report a vulnerability**.
2. Alternativa: correo a `61630997+JAPerezC@users.noreply.github.com` con descripción, pasos para reproducir e impacto.

## Tiempos de respuesta

- Acknowledgement: ≤72 horas
- Análisis inicial: ≤7 días
- Fix/mitigación según severidad: críticas ≤14 días, altas ≤30 días.
